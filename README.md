# Student Performance Analysis & Prediction System

Interactive Python dashboard for analyzing student performance using live Google Sheets data.

## Features
- Live Google Sheets Integration
- Pie Chart Analysis
- Interactive Bar Graph
- Interactive Line Graph
- Failed Student Detection
- Visual Data Representation

## Technologies Used
- Python
- Pandas
- Matplotlib
- mplcursors
- Google Sheets

## Project Demo
This project analyzes student marks and visually represents performance trends using interactive graphs.
